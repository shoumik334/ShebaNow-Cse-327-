# 🛠️ ShebaNow – Local Service Booking Platform

ShebaNow is a web-based platform that helps users find, compare, and book trusted local service providers such as electricians, plumbers, AC technicians, and appliance repair workers.

Users can book appointments, track service requests, make payments, and review completed services through one platform.

---

## 📌 About the Project

ShebaNow provides the following features:

- 🔍 Search and compare service providers by category, price, rating, and distance.
- 📅 Book appointments with date and time slot selection.
- 📍 Track service requests in real time.
- 💳 Secure online payment with receipt generation.
- ⭐ Rate and review providers after service completion.
- 👨‍🔧 Provider dashboard for availability scheduling and job notifications.
- 🔐 Admin panel for provider verification, category management, and dispute handling.
